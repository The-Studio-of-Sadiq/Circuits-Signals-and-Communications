# Circuits, Signals and Communications

**Book 3 — The Circuits, Signals & Communications Core**

The theory of electrical networks, continuous- and discrete-time signals, system behaviour, information transmission and communication channels. This is the core that connects mathematical methods with almost every other EEE discipline: circuit laws and network theorems, transients and AC power, two-ports and transmission lines, signals and LTI systems, sampling and DSP, analog and digital communication, information theory, wireless, optical and RF links, and introductory feedback control.

**Read the book as a PDF:** [`pdf/Circuits-Signals-and-Communications.pdf`](pdf/Circuits-Signals-and-Communications.pdf)

## Build the PDF

Requires Node.js ≥ 18 and a local Chrome, Edge or Chromium (set `CHROME_PATH` if it is not found automatically).

```bash
npm install
```

```bash
npm run pdf
```

This writes `dist/Circuits-Signals-and-Communications.pdf` (KaTeX-rendered math, clickable contents, PDF bookmarks). Build selected part openers or chapters with:

```bash
node scripts/build-pdf.mjs --parts P3,11,12 --out dist/excerpt.pdf
```

## Figures

Every figure is specified by a `<!-- FIGURE ... -->` marker at the point it belongs in its chapter and drawn by `figures/scripts/chNN.py`. Requires Python 3 with numpy, scipy, matplotlib and schemdraw.

Regenerate all figures (or `python scripts/build-figures.py ch06 ch14` for some):

```bash
npm run figures
```

Place newly drawn figures below their markers:

```bash
node scripts/insert-figures.mjs
```

Regenerate the figure plan [`FIGURES.md`](FIGURES.md):

```bash
npm run figures:plan
```

## MCP server

```bash
claude mcp add circuits-signals -- node /absolute/path/to/this/repo/mcp/server.mjs
```

Tools: `list_contents`, `read_part`, `search_book`, `list_figures`, `get_figure`, `build_pdf`. See [`mcp/README.md`](mcp/README.md).
